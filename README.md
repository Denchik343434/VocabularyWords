# Словотека

Приложение для заучивания словарных слов.

## Возможности
- Режим изучения
- Режим теста
- Редактирование библиотек
- Поддержка аудиоформата MP3

## Известные проблемы последнего релиза
- Индикатор несохранённых изменений в режиме редактирования работает некорректно
- Визуальные баги, связанные с отрисовкой кадров (предположительно из‑за графического сервера X11)
- Недоработки, которые могут быть связаны с окружением рабочего стола Cinnamon

## Планы
- Исправить проблему с невыбранными библиотеками в режиме теста
- Реализовать запись аудио внутри приложения
- Создать Android-версию
- Добавить сортировку слов в библиотеке и перемешивание в режиме теста
